# Food Image Classification With Transfer Learning
This project focuses on developing an end-to-end pipeline to train
a deep learning model that can classify different kind of food images using **transfer learning**.

## Description
This project is an end-to-end pipeline to train a deep learning model to classify food images.
You can build a model with that, you can build food classifiers and make predictiosn about custom images.

## Dataset
This project uses a subset of **Food-101 dataset**, which contains images from various categories.

[Dataset source](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/)

For this project, only a few selected classes from the dataset are used to simplify training
and experimentation.
