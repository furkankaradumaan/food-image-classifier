# Problem
This project solves the problem to classify different images from 6 different
categories.

Building a deep learning model to classify the images into these categories.

## Success Metrics
- %85+ accuracy
- %85+ f1-score for each class

## Dataset
FOOD-101 dataset will be used for this project. Because:
- Various images for 101 food categories (6 of them will be used.)
- Images are as in the real world.
- Suitable for incrementing the number of categories in future.
